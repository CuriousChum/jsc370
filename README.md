# Description

This project is my project for the JSC370 (Data Science II) course. 

This project explores the relationship between device temperature and resource usage such as CPU activity, in-use memory, and network activity (upload/download). To reproduce the report locally, install the dependencies and run `jupyter-book`

```bash
pip install -r requirements.txt
jb build .
```
